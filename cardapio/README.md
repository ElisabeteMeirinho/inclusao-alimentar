# Cardapio Inclusivo - Firebase (V9)

As telas empresa.html e gestao.html usam Firebase Authentication e Firestore, e a seguranca depende das regras em firestore.rules. A vitrine antiga (index.html e loja.html) permanece demonstrativa usando localStorage, nao representa os cadastros reais. A aprovacao NAO habilita gestao real de produtos, pagamentos ou pedidos.

Veja INSTRUCOES-FIREBASE.md na raiz para configurar passo a passo. Nunca coloque credenciais privadas em config.js.
