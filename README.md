# Inclusão Alimentar

Site estático informativo do movimento independente Inclusão Alimentar.

## Como publicar pelo GitHub Pages

1. Crie um repositório público `inclusao-alimentar`.
2. Envie **os arquivos e a pasta `assets` de dentro desta pasta** para a raiz do repositório, incluindo `index.html`.
3. Em **Settings > Pages > Build and deployment**, selecione **Deploy from a branch**, `main`, `/(root)` e **Save**.
4. O endereço esperado será `https://SEU-USUARIO.github.io/inclusao-alimentar/`.

## Observações

- Os links oficiais das duas ideias legislativas estão nos cartões da página inicial.
- Status das ideias foi informado pela autora em 27/10/2026; atualizar manualmente quando o Senado confirmar a publicação.

- Esta é uma iniciativa independente e não um site governamental.
- A foto principal foi fornecida pela autora do projeto; confirme que você tem o direito de publicá-la online.
